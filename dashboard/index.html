Same signer vs new signers

Every model is trained on the Kaggle dataset (one signer), then scored on its own test clips and on 167 INCLUDE clips of the 9 shared words, signed by other people. Choice of 61 words; guessing scores 1.6%.

Same signer (Kaggle test)New signers (INCLUDE)

On the same signer every model scores 97–100%, so that test cannot choose a model. On new signers they fall to 0–25%: keypoint models hold up far better than the pretrained pixel CNNs, which learned one person's look rather than the sign.

Improving accuracy on new signers

The new-signer clips are split in half: the dev half chooses the setting, the test half is reported. Aspect fix: MediaPipe measures x in frame widths and y in frame heights, so INCLUDE's 1920×1080 bodies looked twice as tall as Kaggle's 640×720 ones; x is now put in frame-height units. Trim: cut the resting frames before and after the sign.

Bugs found and fixed along the way

  • Frame shape. Features depended on the video's width-to-height ratio; fixed with the aspect correction (opt-in until the final model is retrained).
  • Mirror augmentation. Swapped the hands but not the arms; fixed and every experiment rerun.
  • Live app. Fed the model a mirrored frame; now only the window is mirrored.
